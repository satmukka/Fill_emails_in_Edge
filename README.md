# Fill_emails_from_Excel_in_Edge_Broswer
This browser extension is used to read email ids from an excel/csv file and paste one at a time in the recipient box (created for specific tool, but can be modified for any other requirements)

Download and save all these files into a single folder and select this folder while adding 'unpacked' extension in Edge browser. Refer to 'ReadMe.Docx' file for detailed instructions.
